# 模拟资料：256T 规格下行测试（示例）

> 这是学习用 Mock 文档，不替代真实规格 Markdown。使用真实资料时替换 references/ 即可。

## 对象

- 网元能力：256T 下行吞吐相关特性
- 典型场景：单用户 / 多用户下行业务建立与数据转发

## 关键检查点

1. 下行承载建立是否成功（信令流程完整）
2. 吞吐是否达到规格门限（具体门限以版本发布说明为准，此处记为「待确认门限」）
3. 异常掉线后的恢复行为
4. 与组网拓扑相关的路由/邻区配置是否匹配

## 常见失败形态（供分析引用）

- 版本协议不匹配：握手失败、IE 缺失
- 用例脚本问题：断言字段名错误、时序过紧
- 环境问题：逻辑组网无可用物理资源、链路不通

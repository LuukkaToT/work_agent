# 5G 基带基础测试点：覆盖基线（Mock）

> 学习用 Mock 资料，不替代真实规范或正式 3GPP 文档。

## 正常功能

验证配置下发、资源生效、业务触发、数据或控制信息传输、状态更新以及释放流程。每个场景应给出空口、基带日志或计数器中的至少一个观察点。

## 边界组合

关注最小和最大配置值、资源数量边界、时域与频域边界、能力组合边界，以及参数在合法范围临界点附近的行为。

## 异常与冲突

关注资源重叠、资源不足、非法或不一致配置、消息丢失、定时器超时、调度冲突和上下层状态不一致。异常场景需要同时检查拒绝、降级或告警行为。

## 重配置

检查业务态参数更新、新旧配置切换时机、切换窗口内的数据连续性、旧资源释放，以及重复下发或部分失败时的幂等性。

## 恢复

检查链路失败、超时、重建、复位或重启后的资源清理与业务恢复。恢复场景需要明确恢复时间、状态一致性和残留资源观察点。

# 5G 基带可靠性与可观测性测试点（Mock）

## 可靠性

- 连续重配置时不应出现资源泄漏或状态机卡死。
- 部分配置失败后应保持可解释的旧配置或进入明确失败状态。
- 模块重启、单板复位或链路短时中断后，需要检查配置恢复和业务重建。

## 并发

多 UE、多小区或多个过程同时触发时，检查资源竞争、调度公平性和关键控制信息时延。

## 可观测点

- RRC/MAC/PHY 配置日志及错误码。
- 空口消息与 DCI/UCI 解码结果。
- HARQ、BLER、吞吐、时延和资源利用率计数器。
- 超时、重传、资源冲突和恢复相关告警。
